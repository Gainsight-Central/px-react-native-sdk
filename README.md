# Installation

GainsightPX is available through npm.

### npm

```json
 "dependencies": {
    "other-dependency": "x.x.x",
    "@gainsight-px/react-native-gainsight-px": "https://github.com/Gainsight-Central/px-react-native-sdk.git"
  }
```

OR

```
npm install https://github.com/Gainsight-Central/px-react-native-sdk.git --save
```

ALSO it's available directly [on npm](https://www.npmjs.com/package/@gainsight-px/react-native-gainsight-px)

```
npm i @gainsight-px/react-native-gainsight-px
```

### Expo

Run the expo commands as directed after installing the package.

```
npx expo prebuild
```

```
npx expo run:ios
```

```
npx expo run:android
```

## Usage

```javascript
import { GainsightPX, Configurations, PXUser } from "@gainsight-px/react-native-gainsight-px";
```
